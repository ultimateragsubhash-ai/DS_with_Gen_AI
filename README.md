# Data Science with Generative AI

This repository contains Jupyter notebooks for learning Python programming
and NumPy as foundations for data science and generative AI. The lessons move
from Python basics through functions, error handling, and object-oriented
programming, then introduce NumPy arrays and operations.

## Getting started

Open a notebook in Jupyter Notebook, JupyterLab, or Visual Studio Code with
the Jupyter extension. Choose a Python environment with the packages needed
for that notebook, then run cells from top to bottom.
