# Python Learning Notes

This repository contains beginner-friendly Python study material in Jupyter
Notebook format. The current notebook introduces variables, naming
conventions, assignment, and operators with examples and explanations.

## Contents

- [`Python/1.Variables_Naming_Conventions_Operators.ipynb`](Python/1.Variables_Naming_Conventions_Operators.ipynb) — notes and exercises on Python variables and objects, `id()` and identity, identifier naming rules, and operators.

## Getting started

1. Open the notebook in Visual Studio Code or another Jupyter-compatible
   environment.
2. Select a Python environment with Jupyter support.
3. Run the cells from top to bottom and try changing the examples.

The notebook uses Python's built-in functionality; no project-specific
dependencies are currently required.
